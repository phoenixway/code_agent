# Приклади Go для початківців

Ця папка містить добре коментовані приклади мови програмування Go (Golang) для абсолютних початківців. Кожен файл охоплює один конкретний аспект мови.

## Як користуватися

1. **Встановіть Go**: Завантажте та встановіть Go з [офіційного сайту](https://go.dev/dl/)
2. **Запускайте приклади**: Для кожного файлу виконайте:
   ```bash
   go run 01_hello_world.go
   ```
3. **Експериментуйте**: Змінюйте код, щоб краще зрозуміти як працює мова

## Основні концепції Go

- **Проста синтаксис**: Go має чистий та простий синтаксис
- **Статична типізація**: Типи перевіряються під час компіляції
- **Супутня компіляція**: Немає віртуальної машини, програма компілюється в один бінарний файл
- **Вбудована підтримка конкурентності**: Горутини та канали для паралельного виконання
- **Збирач сміття**: Автоматичне управління пам'яттю

## Поради для початківців

1. Почніть з `01_hello_world.go`
2. Вивчайте по одному файлу за раз
3. Не поспішайте - розуміння основ важливіше за швидкість
4. Експериментуйте з кодом, змінюйте його та спостерігайте результат
5. Використовуйте `go fmt` для автоматичного форматування коду

## Корисні команди Go

```bash
# Запустити програму
go run файл.go

# Скомпілювати програму
go build файл.go

# Встановити залежності
go mod init назва_проекту

go get пакет

# Відформатувати код
go fmt

# Перевірити код на помилки
go vet
```
